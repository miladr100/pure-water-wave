# Glossário

Termos como o HJ Team os usa. A interface do painel usa estas palavras, nesta
grafia (português do Brasil).

| Termo | Significado |
|---|---|
| **HJ Team** | O conjunto de jovens em formação nos programas do movimento (HJ Academy, HJ Rang, Pure Water, Shin Top Gun, UPA). São os usuários do painel. |
| **Programa** | O grupo de formação a que o membro pertence: HJ Academy (HJA, com turmas 1, 2 e 3), HJ Rang (HJR), Pure Water (PW), Shin Top Gun (STG), Universal Peace Academy (UPA). Na planilha de RM aparece como "Curso". No painel, **curso** é só um curso em vídeo da academia. |
| **Turma** | Uma geração de um programa ("16ª Turma" do HJ Rang, "Turma 2026" do Pure Water). |
| **Membro** | Pessoa do HJ Team com conta no painel. Sinônimo na academia: aluno(a). |
| **Educador(a)** | Responsável por membros e equipes; administra o painel. Nunca "tutor" (termo rejeitado). |
| **Capitão / Capitã** | Membro que lidera uma equipe durante um projeto. |
| **Equipe** | Grupo de membros com um capitão, dentro de um projeto. Na planilha: "Time". |
| **Projeto** | Campanha com data de início e fim: "RM 30 dias", "40 dias de testemunho", "120 dias de testemunho". Tem tipo **arrecadação** ou **testemunho**. |
| **Período** | Subdivisão de um projeto (três períodos de 40 dias). |
| **Linha de frente** | O trabalho de rua, de RM ou de testemunho. |
| **Restauração Material (RM)** | Arrecadação de fundos vendendo produtos na rua. |
| **Relatório diário** | O que cada membro envia ao voltar da linha de frente. |
| **Dinheiro / Pix** | Resultado em espécie / resultado digital. |
| **Líquido** | Resultado depois das despesas do dia. A fórmula oficial é decisão pendente. |
| **Meta interna** | Propósito pessoal do membro para o dia, em texto. |
| **Meta externa** | Valor em dinheiro que o membro se propõe a arrecadar no dia. |
| **Nova meta** | Meta diária recalculada a partir da média do membro. |
| **Recorde** | Maior resultado diário do membro no projeto. |
| **Rest / descanso** | Dia sem linha de frente (domingos no RM de 2026). |
| **Produto / material** | Item vendido na RM: abridor, borracha 3D, borracha normal, chaveiro auto… |
| **Levou / Voltou / Restaurou** | Unidades que o membro levou, trouxe de volta e vendeu ("restaurou") no dia. |
| **Dízimo** | Parte do resultado destinada à igreja. Se entra na conta do líquido é decisão pendente. |
| **Estadia** | Custo de hospedagem da equipe durante o projeto (modelo do sistema de Wang Song). |
| **Testemunho** | O trabalho de acompanhar pessoas até a adesão ao movimento. |
| **Convidado(a)** | Pessoa acompanhada por um membro. Sinônimo histórico: filho(a) espiritual. O membro responsável é o **pai/mãe espiritual**. |
| **Jornada** | O caminho do convidado: Pré-Gateway → Gateway → Sistema 1 → Sistema 2. |
| **Pré-Gateway** | Do primeiro contato no campo até a primeira participação no centro. |
| **Gateway** | Participação em atividades de integração no centro CARP ou na igreja (conversas, filmes, home groups, eventos). |
| **Sistema 1** | Série de 16 vídeos (conferências) estudados com o convidado. |
| **Sistema 2** | Estudo do livro (individual, coletivo ou em seminários). |
| **Conferência** | Cada um dos 16 vídeos do Sistema 1. |
| **Ficha de membro** | Documento que o convidado assina ao aderir; pode ser anexado em PDF. |
| **Jardim** | Cidade onde acontece o seminário de aprofundamento; "confirmado para Jardim" e "passagem comprada" são marcos. |
| **CARP** | Centro universitário do movimento onde acontecem as atividades do Gateway. |
| **Home group** | Reunião pequena de integração no centro. |
| **Oração CSW** | Condição espiritual registrada na linha do tempo do convidado ("CSW – 1000x"). |
| **Linha do tempo** | Histórico do convidado: marcos automáticos e acontecimentos registrados pelo membro. |
| **Próximo objetivo** | O marco que falta para o convidado avançar de etapa, com sugestão de como chegar lá. |
| **Pastor(a)** | Usuário da biblioteca do site; não participa do painel. |
| **Biblioteca** | A área de livros e materiais do site (purewaterwave.org/biblioteca). |
| **Academia** | Os cursos em vídeo do site, agora um módulo do painel. |
| **Painel** | A área privada do site para o HJ Team: início, arrecadação, testemunho, academia e administração. |
